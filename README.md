# 📊 Retail & Sales Analysis Dashboard – Tableau

## 📌 Project Overview
This project focuses on analyzing retail sales data using Tableau Public. The interactive dashboard helps explore sales performance, profitability, product categories, and regional business trends.

## 🎯 Project Objectives
- Analyze overall sales and profit performance.
- Identify top-performing product categories and sub-categories.
- Compare sales across different regions.
- Understand sales trends and business performance.
- Create an interactive dashboard for data-driven analysis.

## 📂 Dataset Details
- **Dataset Name:** Sample Superstore
- **Format:** Excel / CSV
- **Domain:** Retail and Sales Analytics
- **Data Includes:** Orders, sales, profit, quantity, discounts, product categories, customer segments, and regional information.

## 📊 Dashboard Features
- Sales Analysis

- Category-wise Sales and Profit

## 🔍 Key Findings
- Sales and profit can be compared across product categories.
- Regional analysis helps identify differences in sales performance.
- Sub-category analysis helps highlight strong and weak performers.
- Monthly trends help explore changes in sales over time.
- Interactive filters make it easier to investigate business performance.
